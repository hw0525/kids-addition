# 🧸 小小加法樂園

給 4–6 歲幼兒的互動加法練習網頁。

孩子拖曳球、按「交換看看」，就能看到 **3 + 4 和 4 + 3 都等於 7**（加法交換律）。老師或家長也可以一鍵產生能直接列印的 A4 看圖加法學習單。

- ✅ 5、10、20、30 以內都可以練習
- ✅ 單一 `index.html`，不需安裝、不需伺服器、不需帳號
- ✅ 所有內容都在瀏覽器中執行，不收集任何資料
- ✅ 支援平板觸控拖曳、電腦滑鼠操作

## 功能

### 🎈 玩一玩（互動練習）

| 功能 | 說明 |
|---|---|
| 數字和球對應 | 上方是算式，下方兩個籃子用「10 格」排法放球，球數和數字永遠對應 |
| 拖曳球 | 把球拖到另一個籃子，3+4 會變成 2+5、1+6……總數不變 |
| 🔁 交換看看 | 左右兩個籃子連同數字一起交換位置，3+4 → 4+3。球的顏色跟著球走，看得出還是同一堆球 |
| 🧮 合起來數一數 | 把兩邊的球合在一起，一顆一顆數給孩子看（有聲音和語音） |
| 點數字回答 | 答對有音效、語音朗讀和彩帶；答錯兩次會自動帶孩子一起數 |
| 點球數數 | 輕點球，球上會出現 1、2、3…… |
| 我的發現 | 記下孩子做過的算式；正反都做過時，自動出現 ✨ `3 + 4 ＝ 4 + 3` |
| 🎲 換一題 | 隨機出題，可選 **5／10／20／30 以內**，也可選擇是否出現 0 |
| − / ＋ | 籃子下方的小按鈕，讓大人自訂題目 |
| 🔊 聲音開關 | 可關閉音效與語音 |

**不同範圍的籃子大小**

| 範圍 | 每個籃子 | 每個加數最大 | 合起來數一數 |
|---|---|---|---|
| 5、10 以內 | 1 個 10 格 | 10 | 1 個 10 格 |
| 20 以內 | 1 個 10 格 | 10 | 最多 2 個 10 格 |
| 30 以內 | 2 個 10 格 | 20 | 最多 3 個 10 格 |

每滿 10 格中間會有一條虛線分隔，幫助孩子建立「一個十、兩個十」的概念。

### 📝 學習單（列印用）

![學習單畫面](screenshots/worksheet.png)

| 設定 | 選項 |
|---|---|
| 題數 | 6、8、10、12、16 題 |
| 範圍 | 5、10、20、30 以內 |
| 圖案 | 球、蘋果、星星、愛心、小魚，或混合 |
| 題型 | 看圖算答案、交換配對（3+4 / 4+3）、看圖寫算式，可複選 |

- **看圖算答案**：`4 + 3 = □`
- **交換配對**：同一組數字正反各一題，再加一題 `3 + 4 = 4 + □`
- **看圖寫算式**：只有圖案，孩子自己寫 `□ + □ = □`
- 每頁有姓名、日期欄，圖案每 5 個一排、每 10 個一組，方便數
- 👀 顯示答案：先在畫面上確認題目
- 🖨️ 列印：直接印成 A4，或在列印視窗選「另存為 PDF」
- ⬇️ 下載：存成一個 HTML 檔，之後離線也能打開列印
- 勾選「附答案頁」時，列印或下載都會附上答案頁

## 放到 GitHub Pages

### 方法一：用 GitHub 網頁操作（不需要指令）

1. 登入 GitHub，按右上角「＋」→「New repository」
2. Repository name 填 `kids-addition`，選 **Public**，按「Create repository」
3. 在新 repository 頁面點「uploading an existing file」
4. 把這個資料夾裡**所有檔案和 `screenshots` 資料夾**一起拖進去，按「Commit changes」
5. 進入 **Settings → Pages**
6. 「Build and deployment」的 Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
7. 等 1–2 分鐘，重新整理 Pages 頁面，上方會出現網址：

   `https://<你的帳號>.github.io/kids-addition/`

### 方法二：用 git 指令

```bash
cd kids-addition
git init
git add .
git commit -m "小小加法樂園"
git branch -M main
git remote add origin https://github.com/<你的帳號>/kids-addition.git
git push -u origin main
```

推上去後，再照方法一的第 5–7 步開啟 GitHub Pages。

### 之後要更新

只要把新的 `index.html` 上傳覆蓋（網頁上「Add file」→「Upload files」），約 1 分鐘後網站就會更新。

## 教學使用建議

1. **先用 3 + 4 開始**：網頁一打開就是 3 + 4，讓孩子先數球、點答案
2. **再按「交換看看」**：問孩子「換過來，答案會變嗎？」，讓孩子再數一次
3. **拖一顆球過去**：問「現在是幾加幾？還是 7 嗎？」，讓孩子發現同一個數有很多種組合
4. **看「我的發現」**：和孩子一起讀出 `3 + 4 ＝ 4 + 3`
5. **最後印學習單**：選「交換配對」題型，讓孩子在紙上再練習一次

建議 4 歲先從 **5 以內**開始，熟悉後再到 10 以內；20、30 以內適合已經會數到 30、開始認識「十」的孩子。

## 常見問題

**Q：沒有語音？**
語音使用瀏覽器或系統內建的中文語音，有些裝置沒有安裝中文語音。沒有語音時仍會有音效，其他功能不受影響。

**Q：在手機上拖曳會捲動畫面？**
請按住球本身再拖，不要按在籃子外面。建議用平板，畫面較大、孩子比較好操作。

**Q：列印出來有空白頁或被切掉？**
在列印視窗中，紙張選 **A4**、邊界選 **無** 或 **預設**、縮放選 **100%**，並勾選「背景圖形」讓顏色印出來。

**Q：沒有網路可以用嗎？**
可以。字型會從 Google Fonts 載入，離線時改用系統字型，所有功能照常。
